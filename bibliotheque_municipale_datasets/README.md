# Datasets — Bibliothèque municipale

Chaque fichier contient 100 lignes de données + 1 ligne d'en-tête.

Fichiers :
- readers.csv : abonnés de la bibliothèque
- books.csv : catalogue de livres
- loans.csv : emprunts
- events.csv : animations organisées par la bibliothèque
- registrations.csv : inscriptions aux animations
